# Story 28.3 第一轮对抗性审查修复报告

**审查时间:** 2026-03-05
**文档版本:** v1.1

## 修复的问题清单

### 1. MatcherRegistry 线程安全问题 ✅
**问题:** 类变量在多线程环境下存在竞态条件
**修复:** 添加 `RLock` 保护所有共享状态访问

### 2. derive_point_prefix 性能问题 ✅
**问题:** 每次调用都复制整个字典
**修复:** 改用 `get_rule()` 直接获取单个规则，避免字典复制

### 3. 注册机制缺少卸载功能 ✅
**问题:** 只能全部清空，无法按来源卸载
**修复:**
- 添加 `unregister(source)` 方法
- 为每个规则添加 `_source` 标记
- 实现 `unregister_demo_rules()` 函数
- 在 `demo_shutdown()` 中自动卸载

### 4. get_floors_from_db 缺少缓存 ✅
**问题:** 每次调用都查询数据库
**修复:** 使用 `lru_cache` 实现 1 小时 TTL 缓存

### 5. match_circuit_from_db 查询逻辑不完整 ✅
**问题:** 假设表结构未验证，字段名可能不存在
**修复:**
- 明确表结构定义（添加注释说明）
- 使用 `floor_id` 外键而非 `floor_code` 直接匹配
- 使用 `category` 字段而非 `circuit_type`
- 添加 `DEVICE_TYPE_TO_CATEGORY` 映射

### 6. building_points.py 迁移影响未评估 ✅
**问题:** 未列出哪些文件导入了它
**修复:** 在 AC5 中明确列出需要验证的文件清单

### 7. 测试用例覆盖不足 ✅
**问题:** 测试场景不全面
**修复:** 添加测试:
- 线程安全测试
- 规则卸载测试
- 空数据库场景
- 排序正确性验证
- 回路未找到场景

### 8. 集成测试环境隔离问题 ✅
**问题:** 直接修改 `os.environ` 影响其他测试
**修复:** 使用 `pytest.monkeypatch` fixture 隔离环境变量

### 9. 回滚策略缺失 ✅
**问题:** 没有回滚方案
**修复:** 添加风险 4，包含:
- Git feature branch
- 数据库备份
- Feature Flag
- 灰度发布策略

### 10. DistributionCircuit 表结构假设未验证 ✅
**问题:** 字段名假设可能错误
**修复:** 在代码注释中明确表结构定义

### 11. identify_point_usage 实现过于简单 ✅
**问题:** 容易误判告警类点位
**修复:** 添加多层匹配策略，先排除告警/状态类点位

### 12. Phase 顺序依赖未明确 ✅
**问题:** 不清楚是否可以并行
**修复:** 在实施步骤中明确标注依赖关系和执行顺序

### 13. demo_startup 错误处理缺失 ✅
**问题:** 注册失败会导致整个 demo 启动失败
**修复:** 添加 try-except 错误处理，允许 demo 继续启动

### 14. AC6 验证标准模糊 ✅
**问题:** "所有主系统服务"定义不清
**修复:** 明确列出需要测试的服务清单

### 15. 文档与代码不一致风险 ✅
**问题:** `sync_devices` 示例代码有未定义变量
**修复:** 完善示例代码，添加完整的实现逻辑
