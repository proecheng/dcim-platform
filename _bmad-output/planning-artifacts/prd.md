## 1. 问题陈述

数据中心运维面临设备分散、能耗高、告警响应慢、资产管理混乱等问题。DCIM 系统通过统一平台整合环境监控、告警管理、能源优化、资产运维等功能，降低运营成本，提升运维效率。

## 5. 范围与约束

### 范围内
- DCIM 核心功能完善和质量提升
- 测试覆盖补全
- 缺失 UI 页面补全
- 已禁用功能启用

### 范围外
- 数字孪生大屏系统（下一阶段）
- 真实设备协议对接（Modbus/SNMP）
- 移动端 App
- 多租户支持

### 约束
- 前端必须兼容现有 Vue 3 + Element Plus 技术栈
- 后端必须保持 FastAPI 异步架构
- 数据库迁移必须通过 Alembic 管理
- ML 模块保持可选（torch 未安装时跳过）

## 6. 风险

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| bcrypt 版本兼容性 | 登录失败 | 锁定 bcrypt==4.0.1 |
| numpy 缺失导致优化路由禁用 | 功能不完整 | 添加 numpy 到 requirements.txt |
| SQLite 11GB 数据库性能 | 查询变慢 | 迁移到 PostgreSQL |
| 测试覆盖率极低 | 回归风险高 | 优先补全核心模块测试 |
| 类型错误（LSP 报告 100+） | 代码质量 | 逐步修复类型标注 |
