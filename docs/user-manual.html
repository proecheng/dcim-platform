版本: V1.0

更新日期: 2026-01-27

适用版本: DCIM 智能数据中心监控管理平台

1. 系统概述

1.1 系统简介

算力监控系统（DCIM - Data Center Infrastructure Management）是一套智能化的数据中心基础设施管理平台，提供从实时监控、能源管理、资产追踪到运维管理的全方位解决方案。

截图位置: 用电监控页面

PUE指标说明

PUE范围 等级 颜色 说明
< 1.4 优秀 🟢 绿色 能效优秀，处于行业领先水平

4.3 节能中心

节能中心是能源优化的核心模块，提供从分析到执行的完整闭环。

截图位置: 节能中心页面

4.3.1 Tab页结构

  • 优化总览 - 为初学者设计的快速入口，展示整体优化状况
  • 需量分析 - 分析申报需量与实际用量的关系，发现优化机会
  • 负荷转移 - 分析可转移设备，将高峰负荷转移到低谷时段

需量利用率说明

利用率范围 状态 建议
< 70% 🔴 过低 申报需量偏高，建议下调以减少基本电费
70%-85% 🟢 合理 申报需量合理，保持当前设置
85%-95% 🟡 偏高 接近申报值，注意监控避免超限
> 95% 🔴 危险 存在超申报风险，需立即关注

4.4 执行管理

跟踪节能方案的执行进度和效果。

截图位置: 执行管理页面

统计指标计算说明

指标 计算方式 说明
总计划数 COUNT(所有计划) 包含所有状态的执行计划
预期年节省 SUM(所有计划的expected_saving) 所有计划的预期节省总和
实际年节省 SUM(已追踪计划的actual_saving年化值) 仅统计已完成追踪的计划
总体达成率 实际年节省 / 已追踪计划预期节省 × 100% 仅计算已追踪计划的达成情况

5.3 告警级别说明

级别 颜色 含义 典型场景
严重 🔴 红色 需要立即处理的紧急情况 UPS故障、温度超限、供电中断
重要 🟠 橙色 较严重问题，需优先处理 设备过载、通讯中断
一般 🟡 黄色 一般性告警，需关注 阈值预警、性能下降
提示 🔵 蓝色 信息性提示 设备维护、数据异常

5.4 告警状态流转

活动 (Active) → 确认 → 已确认 (Ack'd) → 解除 → 已解除 (Resolved)

5.5 操作指南

确认告警

  1. 在告警列表中找到需要确认的告警
  2. 点击【确认】按钮
  3. 告警状态变为"已确认"

批量确认

  1. 勾选多条告警记录
  2. 点击【批量确认】按钮
  3. 所有选中的告警变为"已确认"状态

解除告警

  1. 找到已确认的告警
  2. 在问题解决后，点击【解除】按钮
  3. 告警状态变为"已解除"

11. 常见问题

11.1 登录问题

Q: 忘记密码怎么办？

A: 请联系系统管理员重置密码。管理员可在【系统设置】>【用户管理】中点击【重置密码】。

Q: 登录后显示空白页面？

A: 请检查浏览器版本是否符合要求（Chrome 80+），清除浏览器缓存后重试。

11.2 数据问题

Q: 实时数据不更新？

A:

  1. 检查网络连接是否正常
  2. 点击【刷新数据】按钮
  3. 检查对应设备/传感器是否在线

Q: 历史数据查询很慢？

A: 建议缩小查询时间范围，或选择较粗的数据粒度（如小时均值、日均值）。

11.3 告警问题

Q: 如何设置告警通知？

A: 在【系统设置】>【阈值配置】中为监控点位配置告警阈值。超过阈值时系统会自动产生告警。

Q: 误报的告警如何处理？

A:

  1. 确认告警后分析原因
  2. 如为阈值设置不合理，请调整阈值配置
  3. 如为设备问题，请联系运维处理

11.4 能源管理问题

Q: PUE数据不准确？

A:

  1. 检查总表和IT分表的计量是否正确
  2. 确认电表配置是否完整
  3. 检查数据采集是否正常

Q: 节能建议的收益如何计算？

A: 系统基于历史数据、电价配置和优化参数自动计算。计算公式在建议详情中会详细展示。

11.5 系统问题

Q: 系统运行缓慢？

A:

  1. 检查网络延迟
  2. 关闭不必要的浏览器标签页
  3. 清理浏览器缓存
  4. 如持续缓慢请联系管理员

Q: 大屏无法加载3D模型？

A:

  1. 确认浏览器支持WebGL
  2. 检查显卡驱动是否最新
  3. 尝试关闭浏览器硬件加速后重试
