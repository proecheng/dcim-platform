## 已知问题和限制

### 1. 数据模拟器状态

- 当前数据库为空，部分页面可能显示"暂无数据"
- 建议通过 API 手动创建测试数据或运行数据模拟器

### 2. 导出功能

- 导出功能需要额外依赖 `openpyxl` 和 `reportlab`
- 如果导出失败，需要安装依赖：
  ```bash
  cd backend
  .venv\Scripts\python.exe -m pip install openpyxl reportlab
  ```

### 3. WebSocket 实时推送

- 实时监控页面的 WebSocket 连接需要后端支持
- 如果实时数据不更新，检查 WebSocket 连接状态
