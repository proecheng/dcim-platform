## 七、优先级建议

### P0 — 投标必备（直接影响中标）
1. **告警多渠道通知**（短信/钉钉/电话）— 工作量小，效果显著
2. **预测性维护扩展**（空调等设备）— 在现有诊断引擎基础上扩展
3. **BACnet MS/TP方案**（大金空调对接说明）— 文档+协议转换方案

### P1 — 核心差异化（用户重点关注）
4. **AI视觉巡检**（故障灯识别、基础异常检测）— 可先实现基础版
5. **生成式AI助手**（自然语言运维交互）— 集成Claude API
6. **安全行为审计**（视频+门禁违规识别）— 与AI视觉共用基础设施

### P2 — 增强竞争力
7. **What-If仿真增强**（温度场 + 应急预案）
8. **跨系统根因分析**（Zabbix/APM对接）
9. **照明智能联动**

### P3 — 未来预留
10. **CFD数据导入接口**
11. **带宽监控与限流**
