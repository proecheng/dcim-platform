# 发明专利申请书

## 一种基于多约束智能优化的数据中心负荷转移系统及方法

---

## 技术领域

本发明属于数据中心能源管理技术领域，具体涉及一种基于多约束智能优化的数据中心负荷转移系统及方法。

---

## 背景技术

随着数字经济的快速发展，数据中心的能源消耗呈现爆发式增长态势。在电力市场化改革背景下，峰谷分时电价机制为数据中心提供了通过负荷优化降低电费的机会。然而，现有的负荷管理方法存在以下技术问题：

1. **约束建模不完整**：现有方法通常仅考虑单一的功率约束或时段约束，未能综合考虑设备类型特性、运行安全约束、舒适度影响等多维度约束条件，导致转移方案的可行性和可靠性不足。

2. **转移比例确定缺乏数据支撑**：现有方法多采用经验值或固定比例确定可转移功率，未能根据设备历史运行数据自适应地推荐最优转移比例，造成转移潜力未被充分挖掘或过度转移影响业务运行。

3. **实时调度响应能力不足**：现有方法缺乏基于需量预测的实时预警和自动调整机制，无法在15分钟需量考核窗口内及时响应功率波动，难以避免需量超标导致的高额电费惩罚。

4. **效果追踪机制缺失**：现有方法缺乏从方案执行到效果评估的闭环反馈机制，无法准确量化实际节省效果，难以持续优化转移策略。

因此，需要一种能够综合考虑多维度约束、基于历史数据智能推荐、支持实时调度响应、具备闭环效果追踪能力的负荷转移系统及方法。

---

## 发明内容

### 发明目的

针对现有技术的不足，本发明提供一种基于多约束智能优化的数据中心负荷转移系统及方法，旨在解决现有负荷转移方案约束建模不完整、转移比例确定缺乏数据支撑、实时调度响应能力不足、效果追踪机制缺失等技术问题。

### 技术方案

#### 一、系统架构

本发明提供的负荷转移系统包括：

**参数配置模块**：用于配置设备的负荷转移参数，包括但不限于：
- 可转移功率比例（shiftable_power_ratio）
- 允许转移时段（allowed_shift_hours）
- 禁止转移时段（forbidden_shift_hours）
- 最小连续运行时间（min_continuous_runtime）
- 最大转移持续时间（max_shift_duration）
- 最低运行功率（min_power）
- 最大爬坡速率（max_ramp_rate）
- 转移提前通知时间（shift_notice_time）
- 关键负荷标识（is_critical）
- 人工确认要求（requires_manual_approval）

**智能推荐模块**：基于历史运行数据，采用四层约束算法自动计算设备的最优转移比例，包括：
- 最低功率约束层
- 负荷波动空间约束层
- 峰时用电可转移约束层
- 设备类型上限约束层

**转移配置模块**：提供交互式转移方案规划功能，支持：
- 多设备批量选择与规则配置
- 源时段到目标时段的转移规则定义
- 实时节省效益预估
- 智能方案推荐（效益最大化/成本最小化策略）

**实时调度模块**：基于15分钟滑动窗口的需量预测和自动调整，包括：
- 功率读数采集与窗口平均计算
- 需量利用率预测与趋势分析
- 多级预警机制（关注/预警/临界/超标）
- 自动调整指令生成与执行

**执行管理模块**：负责转移方案的执行计划生成、任务调度与状态跟踪，支持：
- 自动执行任务与人工执行任务分离
- 执行进度实时监控
- 任务依赖关系管理

**效果追踪模块**：提供方案执行效果的量化评估与持续优化，包括：
- 执行前后能耗数据对比
- 基于分时电价的成本节省计算
- 达成率评估与结论生成
- 反馈数据驱动的参数优化

#### 二、核心算法

**（一）四层约束的转移比例智能推荐算法**

本发明提出一种基于四层约束的转移比例计算方法，其计算步骤如下：

**步骤1**：计算最低功率约束C₁
```
C₁ = max(0, 1 - P_min / P_rated)
```
其中，P_min为设备最低运行功率，P_rated为设备额定功率。该约束确保设备维持正常运行所需的最低功率不被转移。

**步骤2**：计算负荷波动空间约束C₂
```
C₂ = max(0, (P_max - P_avg) / P_rated)
```
其中，P_max为历史最大功率，P_avg为历史平均功率。该约束基于设备历史运行数据，识别功率波动空间作为可转移潜力。

**步骤3**：计算峰时用电可转移约束C₃
```
C₃ = R_peak × F_type
```
其中，R_peak为峰时用电占比，F_type为设备类型柔性系数。该约束考虑设备在峰时段的用电比例及设备类型的调节灵活性。

设备类型柔性系数F_type的取值如下：
| 设备类型 | 柔性系数 |
|---------|---------|
| 水泵（PUMP） | 0.7 |
| 暖通空调（HVAC） | 0.6 |
| 空调（AC） | 0.5 |
| 冷却塔（COOLING_TOWER） | 0.5 |
| 空气处理机组（AHU） | 0.5 |
| 冷机（CHILLER） | 0.4 |
| 压缩机（COMPRESSOR） | 0.4 |
| 照明（LIGHTING） | 0.8 |

**步骤4**：计算设备类型上限约束C₄

不同设备类型基于其工艺特性设定最大可转移比例上限：
| 设备类型 | 最大可转移比例 |
|---------|--------------|
| 照明（LIGHTING） | 60% |
| 水泵（PUMP） | 50% |
| 暖通空调（HVAC） | 45% |
| 空调（AC） | 40% |
| 冷却塔（COOLING_TOWER） | 40% |
| 空气处理机组（AHU） | 35% |
| 冷机（CHILLER） | 30% |
| 压缩机（COMPRESSOR） | 30% |
| IT设备（UPS/服务器/存储） | 0%（不可转移） |

**步骤5**：综合计算推荐转移比例
```
R_raw = min(C₁, C₂, C₃, C₄)
R_recommended = R_raw × K_safety
```
其中，K_safety为安全系数，取值0.85，确保推荐值保守可靠。

**步骤6**：置信度评估

根据历史数据天数D_data评估推荐值的置信度：
- D_data ≥ 30天：高置信度（high）
- 14 ≤ D_data < 30天：中置信度（medium）
- D_data < 14天：低置信度（low）

**（二）基于15分钟滑动窗口的需量预测算法**

本发明提出一种实时需量预测方法，其计算步骤如下：

**步骤1**：计算当前窗口平均功率
```
P_current_avg = Σ(P_i) / N
```
其中，P_i为窗口内第i个功率采样值，N为采样点数量。

**步骤2**：计算窗口剩余时间
```
T_remaining = (15 - M_window) × 60 - S_current
```
其中，M_window为当前15分钟窗口内已过去的分钟数，S_current为当前秒数。

**步骤3**：计算功率趋势

取最近3个采样点分析趋势：
- 若P[-1] > P[-3] × 1.02，则趋势为上升（up）
- 若P[-1] < P[-3] × 0.98，则趋势为下降（down）
- 否则趋势为稳定（stable）

**步骤4**：预测窗口结束时平均功率
```
T_elapsed = 900 - T_remaining
P_predicted = (P_current_avg × T_elapsed + P_current × T_remaining) / 900

若趋势为上升：
    P_predicted = P_predicted × 1.02
```

**步骤5**：计算利用率和预警级别
```
U = P_predicted / P_demand_target
```

预警级别判定：
| 利用率范围 | 预警级别 |
|-----------|---------|
| U < 85% | 正常（NORMAL） |
| 85% ≤ U < 90% | 关注（ATTENTION） |
| 90% ≤ U < 95% | 预警（WARNING） |
| 95% ≤ U < 100% | 临界（CRITICAL） |
| U ≥ 100% | 超标（EXCEEDED） |

**步骤6**：计算风险评分
```
S_risk = U × 100
若趋势为上升：S_risk += 5
若T_remaining < 300秒：S_risk += 10
S_risk = min(100, S_risk)
```

**（三）自动调整指令生成算法**

当预警级别达到CRITICAL或EXCEEDED时，系统自动生成调整指令：

**步骤1**：计算需要削减的功率
```
P_excess = P_predicted - P_demand_target × 0.95
```

**步骤2**：按优先级生成调整指令

优先级顺序：
1. **储能放电**：若储能系统可用功率P_storage > 0且荷电状态SOC > 20%，优先使用储能放电：
   ```
   P_discharge = min(P_storage, P_excess)
   P_excess = P_excess - P_discharge
   ```

2. **负荷削减**：对可削减设备按优先级排序，依次生成削减指令：
   ```
   P_curtail = min(P_rated × R_curtail, P_excess)
   P_excess = P_excess - P_curtail
   ```
   其中，R_curtail为设备可削减比例。

3. **负荷转移**：对可转移设备延迟启动，避免叠加峰值。

**（四）基于分时电价的效果追踪计算方法**

本发明提出一种精确的效果追踪计算方法：

**对于负荷转移方案**：
```
日节省 = Σ(P_shift × T_shift × (Price_source - Price_target))
追踪期节省 = 日节省 × D_tracking × (5/7)
年化节省 = 日节省 × 250
```
其中：
- P_shift为转移功率（kW）
- T_shift为转移时长（小时）
- Price_source为源时段电价（元/kWh）
- Price_target为目标时段电价（元/kWh）
- D_tracking为追踪天数
- (5/7)为工作日比例
- 250为年工作日数

**达成率计算**：
```
达成率 = (年化实际节省 / 预期年节省) × 100%
```

达成率评估结论：
| 达成率范围 | 评估结论 |
|-----------|---------|
| ≥ 100% | 执行效果优秀，超额完成预期目标 |
| 80-100% | 执行效果良好，基本达成预期目标 |
| 50-80% | 执行效果一般，部分达成预期目标，建议优化执行方案 |
| < 50% | 执行效果不佳，需要分析原因并调整策略 |

## 具体实施方式

### 实施例一：设备转移比例智能推荐

以某数据中心的冷却水泵为例：
- 设备额定功率：100 kW
- 历史30天平均功率：70 kW
- 历史30天最大功率：95 kW
- 最低运行功率：30 kW
- 峰时用电占比：45%
- 设备类型：PUMP

**计算过程**：
1. C₁ = max(0, 1 - 30/100) = 0.70
2. C₂ = max(0, (95 - 70)/100) = 0.25
3. C₃ = 0.45 × 0.7 = 0.315
4. C₄ = 0.50（水泵类型上限）
5. R_raw = min(0.70, 0.25, 0.315, 0.50) = 0.25
6. R_recommended = 0.25 × 0.85 = 0.21（21%）
7. 置信度：高（30天数据）
8. 推荐可转移功率 = 100 × 0.21 = 21 kW

### 实施例二：实时需量预警与自动调整

某数据中心申报需量800 kW，当前状态：
- 窗口内已采集功率：750, 760, 780, 790 kW
- 当前时刻：某15分钟窗口的第12分钟
- 储能可用放电功率：100 kW，SOC：60%
- 可削减设备：空调系统（50 kW可削减）

**计算过程**：
1. P_current_avg = (750+760+780+790)/4 = 770 kW
2. T_remaining = (15-12)×60 = 180秒
3. 趋势判断：790 > 750×1.02=765，趋势为上升
4. P_predicted = (770×720 + 790×180)/900 × 1.02 = 792 kW
5. U = 792/800 = 99%
6. 预警级别：CRITICAL
7. S_risk = 99 + 5（上升）= 104 → 100

**自动调整**：
1. P_excess = 792 - 800×0.95 = 32 kW
2. 生成储能放电指令：32 kW，持续3分钟
3. 执行后预测功率：792 - 32 = 760 kW
4. 新利用率：760/800 = 95%，降至WARNING级别

### 实施例三：负荷转移方案效果追踪

执行某峰谷转移方案7天后进行效果追踪：
- 转移规则：峰时→谷时，功率50 kW，时长3小时
- 峰时电价：1.2元/kWh，谷时电价：0.4元/kWh
- 预期年节省：30,000元

**计算过程**：
1. 日节省 = 50 × 3 × (1.2 - 0.4) = 120元/日
2. 追踪期节省 = 120 × 7 × (5/7) = 600元
3. 年化节省 = 120 × 250 = 30,000元
4. 达成率 = 30,000/30,000 × 100% = 100%
5. 结论：执行效果优秀，超额完成预期目标

## 权利要求书

### 权利要求1

一种基于多约束智能优化的数据中心负荷转移方法，其特征在于，包括以下步骤：

步骤S1：采集设备历史运行数据，包括平均功率P_avg、最大功率P_max、最低功率P_min和峰时用电占比R_peak；

步骤S2：基于四层约束算法计算设备最优转移比例，所述四层约束包括：
- 第一层约束C₁为最低功率约束，C₁ = max(0, 1 - P_min/P_rated)；
- 第二层约束C₂为负荷波动空间约束，C₂ = max(0, (P_max - P_avg)/P_rated)；
- 第三层约束C₃为峰时用电可转移约束，C₃ = R_peak × F_type，其中F_type为设备类型柔性系数；
- 第四层约束C₄为设备类型上限约束，根据设备类型确定最大可转移比例；

步骤S3：综合四层约束计算推荐转移比例R_recommended = min(C₁, C₂, C₃, C₄) × K_safety，其中K_safety为安全系数；

步骤S4：根据历史数据天数评估推荐值的置信度，生成带置信度标识的转移比例推荐结果。

### 权利要求2

根据权利要求1所述的方法，其特征在于，步骤S2中所述设备类型柔性系数F_type根据设备类型确定，其中水泵类设备取值0.7，暖通空调类设备取值0.6，空调类设备取值0.5，冷机类设备取值0.4，照明类设备取值0.8。

### 权利要求3

根据权利要求1所述的方法，其特征在于，步骤S4中所述置信度评估规则为：当历史数据天数大于等于30天时评估为高置信度，当历史数据天数大于等于14天且小于30天时评估为中置信度，当历史数据天数小于14天时评估为低置信度。

### 权利要求4

一种基于15分钟滑动窗口的数据中心需量预测方法，其特征在于，包括以下步骤：

步骤T1：在15分钟需量考核窗口内周期性采集功率读数P_i；

步骤T2：计算窗口内已采集功率的平均值P_current_avg和窗口剩余时间T_remaining；

步骤T3：基于最近三个采样点的功率变化判断功率趋势，当最新功率大于最早功率的102%时判定为上升趋势，当最新功率小于最早功率的98%时判定为下降趋势，其余情况判定为稳定趋势；

步骤T4：预测窗口结束时平均功率P_predicted = (P_current_avg × T_elapsed + P_current × T_remaining) / 900，若趋势为上升则将预测值上调2%；

步骤T5：计算需量利用率U = P_predicted / P_demand_target，并根据利用率阈值确定预警级别；

步骤T6：当预警级别达到临界或超标时，自动生成调整指令，优先使用储能放电，其次按优先级削减可削减设备负荷。

### 权利要求5

根据权利要求4所述的方法，其特征在于，步骤T5中所述预警级别的判定规则为：利用率小于85%为正常级别，利用率在85%至90%之间为关注级别，利用率在90%至95%之间为预警级别，利用率在95%至100%之间为临界级别，利用率大于100%为超标级别。

### 权利要求6

一种基于分时电价的负荷转移效果追踪方法，其特征在于，包括以下步骤：

步骤E1：获取转移方案的配置参数，包括转移功率P_shift、转移时长T_shift、源时段电价Price_source和目标时段电价Price_target；

步骤E2：计算日节省金额：日节省 = Σ(P_shift × T_shift × (Price_source - Price_target))；

步骤E3：计算追踪期节省：追踪期节省 = 日节省 × D_tracking × (5/7)，其中D_tracking为追踪天数，(5/7)为工作日比例；

步骤E4：计算年化节省：年化节省 = 日节省 × 250；

步骤E5：计算达成率并生成评估结论：达成率 = (年化实际节省 / 预期年节省) × 100%；

步骤E6：将效果追踪结果反馈至参数配置模块，用于优化后续转移方案的参数设置。

### 权利要求7

一种基于多约束智能优化的数据中心负荷转移系统，其特征在于，包括：

参数配置模块，用于配置设备的负荷转移参数，包括可转移功率比例、允许转移时段、禁止转移时段、最小连续运行时间、最大转移持续时间、最低运行功率、最大爬坡速率和关键负荷标识；

智能推荐模块，用于基于设备历史运行数据和四层约束算法计算设备的最优转移比例并评估置信度，所述四层约束包括最低功率约束、负荷波动空间约束、峰时用电可转移约束和设备类型上限约束；

转移配置模块，用于提供交互式转移方案规划，支持多设备多规则配置、源时段到目标时段的转移规则定义和实时节省效益预估；

实时调度模块，用于基于15分钟滑动窗口进行需量预测、多级预警和自动调整指令生成；

执行管理模块，用于生成执行计划、调度任务执行并跟踪执行状态；

效果追踪模块，用于基于分时电价计算实际节省效果、评估达成率并生成优化建议。

## 说明书摘要

本发明公开了一种基于多约束智能优化的数据中心负荷转移系统及方法。该系统包括参数配置模块、智能推荐模块、转移配置模块、实时调度模块、执行管理模块和效果追踪模块。本发明提出了基于四层约束（最低功率约束、负荷波动空间约束、峰时用电可转移约束、设备类型上限约束）的转移比例智能推荐算法，能够根据设备历史运行数据自适应计算最优转移比例；提出了基于15分钟滑动窗口的需量预测算法和多级预警机制，能够实时预测需量超标风险并自动生成调整指令；提出了基于分时电价的效果追踪方法，实现了从方案配置到效果评估的闭环优化。本发明解决了现有负荷转移方法约束建模不完整、转移比例确定缺乏数据支撑、实时响应能力不足、效果追踪机制缺失等技术问题，适用于数据中心的智能能源管理场景。
