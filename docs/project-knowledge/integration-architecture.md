## 数据流

### 实时数据流 (5秒循环)

```
模拟器/采集器 → PointHistory → PointRealtime → WebSocket(realtime) → 前端 realtimeStore
                    │
                    ▼
              告警引擎检测
                    │
              ┌─────┴─────┐
              │            │
         创建告警      无告警
              │
              ▼
    WebSocket(alarms) → 前端 alarmStore → 声音通知
```

### 告警处理流

```
告警触发 → Alarm 记录 → 通知分发器 → 通知策略 → 渠道适配器(邮件/短信/微信)
    │                        │
    │                   风暴抑制检查
    │                        │
    ├── 联动策略检查 → 执行联动动作 → 恢复检查
    │
    ├── 超时升级 → AlarmEscalation
    │
    └── 确认/解决 → WebSocket 推送 → 前端刷新
```

### 负荷转移流

```
机会发现 → 约束检查(温度/容量/电价) → 制冷联动 → 计划创建
    │                                       │
    ▼                                       ▼
设备选择 → 收益计算 → 执行任务 → 效果监控 → 报告
```

## 跨层通信协议

### REST API

- 前缀: `/api/v1/`
- 认证: `Authorization: Bearer <JWT>`
- 响应: `PageResponse[T]` 分页 or 直接 Pydantic model
- 错误: `HTTPException(status_code, detail)`

### WebSocket

- 认证: Query parameter `?token=<JWT>`
- 3 通道: `realtime` / `alarms` / `system`
- alarms 通道同时传输: alarm actions + diagnosis messages

### 前端 API 封装

```
前端 → api/request.ts (Axios 拦截器) → /api/v1/* → Express Proxy → FastAPI
                │
                ├── Token 自动注入
                ├── 401 自动跳转登录
                └── ResponseModel 自动解包
```

## 权限模型

### RBAC 三角色

| 角色 | 能力 | 对应依赖 |
|------|------|---------|
| admin | 全部操作 + 用户管理 + 系统配置 | `require_admin` |
| operator | 读写操作 + 设备控制 | `require_operator` |
| viewer | 只读访问 | `require_viewer` |

### 站点隔离

- `UserSite` 多对多关联
- `get_user_site_ids()` 返回用户可访问站点列表
- API 查询自动过滤 `WHERE site_id IN (:user_site_ids)`
- admin 角色不受站点限制
