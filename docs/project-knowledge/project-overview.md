# 项目概览 - 算力中心智能监控系统 (DCIM)

## 系统简介

算力中心智能监控系统（Data Center Infrastructure Management，DCIM）是一套面向数据中心的全栈管理平台，提供环境监控、告警管理、能源优化、资产管理和运维管理等综合功能。系统采用现代化的前后端分离架构，支持实时数据推送、3D 可视化大屏展示和深度学习驱动的能源优化。

## 核心功能模块

### 1. 环境监控

- **实时数据采集** - 每 5 秒采集温湿度、电力、空调等 100+ 监测点位
- **实时数据推送** - WebSocket 双向通信，亚秒级数据更新
- **设备状态监控** - 支持 UPS、空调、配电柜、IT 服务器等设备类型
- **点位类型** - AI（模拟输入）、DI（开关输入）、AO（模拟输出）、DO（开关输出）、CALC（虚拟计算）

### 2. 告警管理

- **多级告警** - 4 级告警（紧急/主要/次要/提示）
- **灵活阈值** - 支持上下限、持续时间、复合规则
- **声音通知** - 紧急告警循环播放，主要告警一次播放
- **告警屏蔽** - 按点位、级别、时间段屏蔽
- **告警统计** - 日统计、趋势分析

### 3. 能源管理（核心）

- **配电拓扑** - 变压器→配电柜→回路→设备的完整配电链
- **PUE 监控** - 实时 PUE 计算和历史趋势
- **能耗统计** - 小时/日/月能耗统计，峰谷平分时段
- **需量管理** - 15 分钟需量监控、超需量预警、历史分析
- **电价管理** - 多时段电价配置（尖/峰/平/谷/深谷）

### 4. 节能优化

- **6 种分析插件** - 峰谷套利、需量优化、PUE优化、功率因数、负荷转移、设备效率
- **方案模板** - A1-A5（无需投资方案）、B1（投资改造方案）
- **节能机会** - 自动识别 4 大类节能机会（电费结构/设备运行/设备改造/综合能效）
- **执行追踪** - 方案执行记录和效果追踪

### 5. 电费综合优化（V3.0）

- **6 类可调度负荷** - 时移型、削减型、调节型、发电型、储能型、刚性
- **日前调度优化** - 96 时段（15分钟粒度）调度计划
- **实时需量控制** - 动态需量预警和调节
- **储能/光伏集成** - 储能系统和光伏系统配置

### 6. VPP 虚拟电厂

- **完整分析报告** - 负荷特性、需量优化、投资回报
- **可调节负荷管理** - 设备分类和调节能力配置
- **电费账单分析** - 分项费用和优化空间

### 7. 3D 数字孪生大屏

- **Three.js 3D 模型** - 数据中心建筑和机柜 3D 可视化
- **热力图** - 温度/功率热力图叠加
- **动态特效** - 功率流动动画、告警脉冲效果
- **多种模式** - 指挥模式、运营模式、展示模式
- **4 种主题** - 科技蓝、线框、逼真、夜间

### 8. 资产与运维

- **资产台账** - 设备资产信息管理
- **机柜管理** - 机柜空间和容量
- **工单管理** - 运维工单流转
- **巡检管理** - 巡检计划和记录
- **知识库** - 运维知识管理

## 技术架构

### 架构图

```
┌─────────────────────────────┐
│        浏览器客户端           │
└──────────┬──────────────────┘
           │ HTTP / WebSocket
┌──────────▼──────────────────┐
│  代理层 (Express, Port 3000) │
│  静态文件 + API 转发 + WS    │
└──────────┬──────────────────┘
           │
┌──────────▼──────────────────┐
│  后端 (FastAPI, Port 8080)   │
│  REST API + WebSocket + ML  │
└──────────┬──────────────────┘
           │
┌──────────▼──────────────────┐
│  数据库 (SQLite/PostgreSQL)  │
│  50+ 表, 时序数据            │
└─────────────────────────────┘
```

### 技术选型

| 层次 | 技术 | 说明 |
|------|------|------|
| **前端** | Vue 3 + TypeScript | Composition API, `<script setup>` |
| **UI 框架** | Element Plus | 企业级 UI 组件库 |
| **图表** | ECharts | 折线、柱状、饼图、仪表盘 |
| **3D** | Three.js | 数据中心 3D 模型和特效 |
| **大屏** | DataV Vue3 | 数据大屏组件 |
| **状态** | Pinia | 7 个全局存储 |
| **构建** | Vite | 快速 HMR 和构建 |
| **后端** | FastAPI | 异步 Python Web 框架 |
| **ORM** | SQLAlchemy 2.0 | 异步 ORM |
| **数据库** | SQLite / PostgreSQL | 50+ 表 |
| **认证** | JWT | OAuth2 兼容 |
| **ML** | PyTorch | GNN, RL, Transformer |
| **代理** | Express | API 转发 + 静态文件 |

## 快速启动

**Windows:**
```batch
start.bat
```

**Linux/Mac:**
```bash
chmod +x start.sh && ./start.sh
```

**Docker:**
```bash
docker-compose up -d
```

启动后访问:
- 系统入口: http://localhost:3000
- API 文档: http://localhost:8080/docs
- 大屏展示: http://localhost:3000/bigscreen
