# 算电协同 — 济南高新区集成电路产业园区智算中心 · 实地调研提纲（数据采集清单）

> **配套**：建设方案 `算电协同系统建设方案.md` §16.4（调研要点摘要）、§10（效益模型）、附录 E（EnergyHub 复用基础）。
> **用途**：现场可打印带走的逐项采集清单；回填后即为送审方案的"**数据来源附件**"。
> **周期**：建议专班组织，2–4 周（先于详细设计与投资决策）。
>
> **优先级**：`P0`=回收/选档生死项（不可缺）｜`P1`=收窄效益区间｜`P2`=锦上添花/远期。
> **状态标注铁律**：每项数据须标 **【已建成 / 在建 / 规划】** + 取数日期 + 数据来源/责任方（**官方台账、电费单、设计图优先于口头**）。

## 0. 调研目标与产出

**目标**
1. 用真实参数回填 §10 效益模型——把"节约+收益 85–285 万/年、回收 2.6–7 年"的区间**收窄**到可决策。
2. 确定 **保守 / 适中 / 最佳** 三档选型（§14.3）。
3. 坐实"园区源网荷储资源可共享调用"这一关键假设（§10.1）。

**产出（交付物）**
1. 回填后的 §10 效益模型（区间收窄、附敏感性）。
2. **数据来源附件**（下方表 T1–T9 + §10 必填参数行，逐项带状态/来源/日期）。
3. 三档选型建议书。
4. §13 组织分工 / §14 商业模式落点 + §13.3 政府协调清单进展。

**方法**：访谈（园区管委会 / 国网济南·山东电力 / 数据中心业主 / 济南高新虚拟电厂运营主体 / 暖通设计方）＋ 查档（能源台账 / 电费单 / 一次系统图 / 设计说明）＋ 现场勘察（机房 / 配电室 / 计量点 / 大屏位）。

## 1. 头号卡点（P0 — 先拿这几样，其余可后补）

> 经验来自同类项目：**电费单 + 负荷曲线**是决定全局口径的生死项，缺它一切效益都是估算。

1. **近 12 个月电费单**（代表月 + 全年汇总）：计费制（两部制 / 单一制）、**需量（容量）电费基数与是否实际计取**、五段式分时电量结构、力调（功率因数）现状、综合到户电价。
   - → 回填 §10.1 电费基数（现假设综合电价 0.6 元/kWh、年电费 2730–2940 万）与需量收益（10–35 万/年）。
   - ⚠ 智算中心**适用需量电费**，**不**享充换电设施"2030 前免收需量电费"（发改综合〔2023〕545 号）——务必确认实际计取的需量基数。
2. **IT 负荷 15 分钟级曲线 ≥ 1 个月** + 装机容量 + 主变压器容量：定 IT 实际 MW、等效利用小时（现假设 6500–7000h）、需量尖峰形态、可转移空间。
3. **园区源网荷储"已建成 vs 规划"官方台账** + **共享调用权与分成机制**：光伏 420MW、储能 220MWh、冰蓄冷 50MWh、水蓄热 30MWh 等，逐项核 **【已建成/在建/规划】**、产权、可否经 VPP 调用、分成口径（现 §10 按数据中心侧分 30–50% 扣减）。
4. **济南高新虚拟电厂接入机制** + **DR/调峰补偿口径与结算主体准入**：决定 DR/调峰收益（15–60 万/年）能否落袋（§13.3 需政府协调）。

## 5. 注意事项（铁律）

- **脱敏**：附件与对外稿**不写公司名（隆海）与客户真名**（如新好科/威盛）；用"某智算中心""园区运营主体""某轮胎制造企业"等脱敏表述。
- **远期不计当期**：光伏 420MW 等含**远期规划**，效益只计【已建成/可调用】部分；规划部分单列、**不进当期回收测算**。
- **官方背书**：源网荷储与电价以官方台账/电费单为准；访谈口径须有文件佐证方可入模型。
- **诚实边界**（送审可信度关键，调研不改变这些边界、只回填数字）：算力一期开环（建议+模拟、不下发）、碳=影子价/ESG（不入现金流）、动态碳因子一期模拟/代理、绿电直连一期不含一次工程。
