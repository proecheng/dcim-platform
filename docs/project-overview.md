# 项目概览

## 系统简介

算力中心智能监控系统 (DCIM - Data Center Infrastructure Management) 是一套面向数据中心的基础设施管理平台，提供实时环境监控、设备管理、告警管理、能源管理、3D 数字孪生、资产运维等全方位功能。

## 系统版本

当前版本: V2.3.3 (部署文档标注)

## 核心功能模块

### 1. 监控仪表盘
- 实时展示机房环境状态、设备运行情况、告警统计
- 支持 AI/DI/AO/DO 四种点位类型，最多 100 个监控点位
- 数据采集间隔 5 秒，WebSocket 实时推送

### 2. 六大监控域 (参照华为 DCIM 架构)

| 域 | 功能 | 路由 |
|----|------|------|
| 供配电管理 | UPS 监控、电池组、配电柜、机柜 PDU、用电监控、能耗统计、配电拓扑 | /power/* |
| 制冷系统 | 精密空调、室外机、冷通道、群控状态 | /cooling/* |
| 环境监控 | 温湿度、烟感、漏水等环境参数总览 | /environment/* |
| 安防消防 | 门禁、消防联动、视频监控 | /security/* |
| 基础设施 | 资产台账、机柜管理、容量管理、空间拓扑、故障影响分析 | /infrastructure/* |
| 节能中心 | 节能分析、负荷调节、执行管理、能效报告 | /energy-saving/* |

### 3. 告警管理
- 四级告警: 紧急 (critical)、重要 (major)、次要 (minor)、提示 (info)
- 告警引擎: 阈值缓存、自动触发、声音通知
- 告警升级: 定时检查未处理告警并升级
- 告警屏蔽: 支持按点位/时间段屏蔽
- 数据质量标记: 防止误报

### 4. 能源管理
- PUE 实时监测与历史趋势
- 配电拓扑可视化
- 峰谷平电费分析
- 需量管理与优化
- 6 种分析插件: 峰谷电价优化、负荷转移、设备效率、PUE 优化、功率因数、需量优化
- 节能机会自动检测 (每小时)
- 效果追踪 (每 6 小时)

### 5. 3D 数字孪生大屏
- Three.js 3D 建筑模型
- 热力图叠加
- 设备详情面板
- 多主题切换 (夜景/写实/线框/科技蓝)
- 自动巡游、键盘快捷键
- 楼层选择与 2D 平面图

### 6. 资产运维
- 资产台账管理
- 机柜 U 位可视化
- 容量四维监控 (空间/电力/制冷/承重)
- 工单管理、巡检管理
- 知识库

### 7. 联动引擎
- 联动策略配置
- 消防分级联动 (交叉确认)
- 联动恢复流程
- 事件时间线报告
- 控制命令分级确认
- 传感器漂移检测

### 8. 智能诊断
- 诊断规则管理
- 故障自动诊断
- 诊断结果展示

### 9. 虚拟电厂 (VPP)
- VPP 方案分析
- 可调度资源配置
- 日前调度优化

### 10. 视频监控
- NVR/摄像头管理
- 视频控制
- 告警回放

## 技术架构

```
浏览器 ──HTTP/WS──> Vite Dev(3000) 或 Express Proxy(3000) ──> FastAPI(8080) ──> SQLite/PostgreSQL
```

### 三层架构

| 层级 | 技术栈 | 端口 |
|------|--------|------|
| 前端 | Vue 3 + TypeScript + Vite + Element Plus + ECharts + Three.js + Pinia | 3000 (dev) / 5173 (vite) |
| 代理 | Express.js (生产) / Vite proxy (开发) | 3000 |
| 后端 | FastAPI + SQLAlchemy 2.0 (async) + Pydantic + JWT + WebSocket | 8080 |
| 数据库 | SQLite (开发) / PostgreSQL (生产) | — |
| 缓存 | Redis (可选) | 6379 |

### WebSocket 通道

| 通道 | URL | 用途 |
|------|-----|------|
| realtime | /ws/realtime?token=xxx | 实时数据推送 (5 秒间隔) |
| alarms | /ws/alarms?token=xxx | 告警通知 |
| system | /ws/system?token=xxx | 系统状态 |

## 后台定时任务

| 任务 | 间隔 | 说明 |
|------|------|------|
| 数据模拟器 | 5 秒 | 为 52 个点位生成模拟数据 |
| 告警引擎刷新 | 30 秒 | 检查阈值版本 |
| 通信监控 | 30 秒 | 检查通信中断 |
| 告警升级 | 60 秒 | 检查未处理告警 |
| PUE 历史记录 | 15 分钟 | 写入 PUE 历史 |
| 能耗聚合 | 30 分钟 | 小时/日/月聚合 |
| 节能机会检测 | 1 小时 | 自动检测节能机会 |
| 效果追踪 | 6 小时 | 追踪节能效果 |

## 认证与权限

- 认证方式: JWT (JSON Web Token)
- 令牌有效期: 8 小时 (开发), 建议生产改为 30 分钟
- 刷新令牌: 7 天
- 角色: admin (管理员), operator (操作员), viewer (查看者)
- 权限模型: RBAC (基于角色的访问控制)
- 默认管理员: admin / admin123

## 数据模拟

系统内置数据模拟采集器，后端启动时自动运行:
- 每 5 秒为点位生成模拟数据
- AI 点位在量程范围内小幅波动 (±2%)
- DI 点位有 0.5% 概率触发告警
- 自动保存到 point_history 表
- 可通过 `SIMULATION_ENABLED=false` 关闭
