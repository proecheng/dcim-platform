## 文档要求（11.5 节）

### 11.5.1 IT 负载占比约束
- IT 负载占 60-80%，不可转移
- 制冷系统占 15-25%，部分可转移
- 配电系统占 3-5%，不可转移
- 照明及其他占 2-5%，可转移
- **公式**：`最大可转移功率 = 总功率 × (制冷占比 × 0.4 + 其他占比 × 0.6)`

### 11.5.2 UPS 容量约束
- 转移后峰值功率 ≤ UPS 额定容量 × 0.8
- 超限时自动减少转移功率或拒绝执行

### 11.5.3 制冷系统联动
- 峰时削减 IT 负载 → 同步降低冷水机组输出
- 谷时增加 IT 负载 → 提前 10-15min 启动冷水机组
- 负载快速变化 → 启用备用冷水机组

### 11.6 制冷与用电联动机制
- 制冷滞后效应预测（15-30 分钟）
- 冷量需求计算
- 制冷系统效率优化（COP 优化）
- 送风温度动态调节
- PUE 优化路径分析
