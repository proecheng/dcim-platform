## 四、技术架构概要

```
浏览器 ──HTTP/WS──> Vite Dev(3000) 或 Express Proxy(3000) ──> FastAPI(8080) ──> SQLite/PostgreSQL
```

| 层级 | 技术栈 |
|------|--------|
| 前端 | Vue 3 + TypeScript + Vite + Element Plus + ECharts + Three.js |
| 代理 | Vite proxy (开发) / Express (生产) |
| 后端 | FastAPI + SQLAlchemy 2.0 (异步) + Pydantic v2 |
| 认证 | JWT + RBAC (admin/operator/viewer) |
| 实时 | WebSocket (realtime/alarms/system 三通道) |
| 数据库 | SQLite (开发) / PostgreSQL (生产) |

## 五、质量保障

- 每个 Story 严格执行四步流程：创建 → 对抗性审查 → 实施 → 代码审查
- 对抗性审查由独立审查 Agent (Momus) 执行，发现问题后修复再实施
- 代码审查同样由 Momus 执行，发现 Critical/High 问题必须修复
- 后端测试覆盖：~80 个 pytest 测试文件，配置 `--cov=app` 覆盖率报告
- 前端构建验证：每次实施后执行 `npm run build` 确认无编译错误
- 前端单元测试：Vitest 框架，11 个测试文件覆盖 stores/composables/views/router/utils
- E2E 测试：Playwright 框架，7 个 spec 文件覆盖 auth/alarm/dashboard/device/energy/navigation/user-management
- CI/CD 流水线：GitHub Actions（ci.yml 后端测试 + 前端构建检查 + 类型检查；cd.yml Docker 镜像构建推送）
